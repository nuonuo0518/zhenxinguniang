### 《遥远的救世主》/ 电视剧《天道》

**作者：** 豆豆 | **剧主演：** 王志文、左小青 | **豆瓣：** 9.1

#### 核心思想

| 概念 | 内容 |
|------|------|
| **文化属性论** | 强势文化=遵循规律、立足自身；弱势文化=等待救主、依赖外力破格获取 |
| **核心命题** | "强势文化造就强者，弱势文化造就弱者，不以人的意志为转移" |
| **哲学基石** | "神即道，道法自然，如来"——规律本身就是神，不可违背也无法代劳 |
| **得救之道** | 没有救世主，只有自己识道自救；等待外力是弱势文化的根本特征 |
| **扶贫本质** | 给钱给资源是强化弱势文化；真正的改变是打破心理结构，让人在压力下用自己的能力活下来 |

#### 核心人物

| 人物 | 本质 |
|------|------|
| **丁元英** | 看穿规律但拒绝成为救世主——因为他知道"救不了"，救了反而是害 |
| **芮小丹** | 强势文化的具体化——独立、清醒、不依附，爱不是因为需要而是因为共鸣 |
| **王庙村农民** | 弱势文化缩影——善良但习惯依赖，遇压力第一反应是求外援 |
| **林雨峰** | 规则内的强者——遇到"破局者"因无法适应而崩溃 |

#### 对游戏的映射

| 《天道》概念 | 游戏设计建议 |
|------------|------------|
| 强势/弱势文化 | 社会化程度的两极重新定义——不是"适应=高分"，而是"清醒程度 × 融入程度"二维坐标 |
| 丁元英：只给规律不给答案 | 高级导师型NPC设计原则——给线索，不救场，"你自己想清楚" |
| 弱势文化=等待破格 | "躺平等提拔"路线的底层逻辑——不是懒，是一种等待外力救济的文化基因 |
| 格律诗破局 | 玩家可用信息差和识人能力对抗比自己级别高的人，而不是靠属性碾压 |
| 得救之道在自身 | 游戏开放结局的底层逻辑——没有正确答案，每条路都是"你自己选的"结果 |

#### 与游戏灵魂句的关系

- 天道：看穿之后选择**旁观**（冷眼）
- 大厂模拟器：看穿之后选择**逃亡**（仍然热烈）
- **差异即温度**——这个游戏比天道更暖，因为它还在乎

### 《凡人歌》/ 原著《我不是废柴》

**作者：** 纪静蓉（同为编剧）| **主演：** 殷桃、王骁 | **豆瓣：** 7.7 | **集数：** 37集

#### 故事结构：三条线、六个人、一面镜

| 线索 | 人物 | 核心矛盾 |
|------|------|---------|
| **主线** | 那伟 × 沈琳 | 精英中产失业 → 夫妻从高处跌落，摆摊重建 |
| **副线A** | 沈磊 × 谢美蓝 | 躺平者 vs 奋斗者 → 价值观撕裂 → 婚姻破裂 |
| **副线B** | 那隽 × 李晓悦 | 新精英 vs 佛系女孩 → 对"值不值得卷"有根本分歧 |

三条线本质是**同一个时代焦虑的三种活法**：卷了又失业 / 不卷但废了 / 继续卷还没到头。

#### 核心人物弧光

| 人物 | 起点 | 弧光 | 关键一句 |
|------|------|------|---------|
| **那伟** | 大厂中层，用职位定义自我 | 失业后不知道自己是谁 → 接受平凡 | 崩溃不是因为没钱，是因为**不知道自己是谁了** |
| **沈琳** | 5年全职主妇，依附家庭 | 被迫回职场屡碰壁 → 自己做卤货，找回主体性 | 从"依附"到"独立主体" |
| **沈磊** | 辞掉高薪互联网，主动躺平 | 是逃避还是清醒？剧不给答案 | 全剧最有争议的人——观众各有答案 |
| **那隽** | 卷王，互联网高薪 | 看哥哥跌落，质疑卷的意义，最终也失业 | 代表"努力卷了也没用"的新一代焦虑 |

#### 核心主题

1. **大厂身份是假安全感** — 用职位定义自我，失业等于失去身份认同
2. **躺平不是答案，卷也不是答案** — 剧不给答案，只给镜子
3. **女性被系统性低估** — 全职主妇的付出不被社会"记分"
4. **阶层焦虑的本质是身份认同危机** — 真正怕的不是没钱，是不知道自己凭什么值这个价

#### 对游戏的映射

| 《凡人歌》设计 | 游戏设计建议 |
|-------------|------------|
| 三条平行叙事线 | 同一家公司里不同选择路线（卷/躺/逃），玩家选一条走，能看到其他人的结局 |
| 失业作为核心转折 | "你被裁了"作为最真实的职场危机触发机制，不是BOSS战 |
| 沈琳的身份认同弧光 | 360评估维度之一：你对自己价值的认知 vs 系统对你的评分 |
| 沈磊的争议性 | 设计一个让玩家自己判断的NPC——高社化玩家觉得他懦弱，低社化玩家觉得他清醒 |
| 没有答案，只有镜子 | 强化开放结局——游戏不评判，只呈现 |

## 二、游戏竞品参考

### 参考游戏机制拆解

#### 《中国式家长》
| 项目 | 内容 |
|------|------|
| 核心机制 | 人生阶段模拟+属性养成，每个阶段做选择影响后续路径 |
| 借鉴点1 | **阶段感设计**：每个人生节点有明确的"里程碑感"，玩家知道自己在哪个阶段 |
| 借鉴点2 | **面子系统**：社会评价维度的量化，可映射为我们的"社会化程度" |
| 规避陷阱 | 属性养成太机械，缺乏真实感；我们要深度而不是广度 |

#### 《Papers Please》
| 项目 | 内容 |
|------|------|
| 核心机制 | 信息审核+规则判断+道德压力，每个决策都有代价 |
| 借鉴点1 | **信息不对称下的判断**：玩家掌握有限信息，需要推理；完全映射"识人"机制 |
| 借鉴点2 | **代价感设计**：每次"做好人"都有成本，没有免费的道德选择 |
| 规避陷阱 | 道德二元化（好人/坏人）；我们的设计没有道德判断，只有认知深度 |

#### 《Florence》
| 项目 | 内容 |
|------|------|
| 核心机制 | 情感叙事+玩法即叙事（拼图碎片代表对话难度变化） |
| 借鉴点1 | **玩法承载情感**：每个小游戏机制本身就是在表达情绪，不是装饰 |
| 借鉴点2 | **节奏控制**：快慢节奏切换制造情绪落差，玩家自然入戏 |
| 规避陷阱 | 体量太短，重玩价值低；我们需要更丰富的内容支撑20h |

#### 《Disco Elysium》
| 项目 | 内容 |
|------|------|
| 核心机制 | 技能检定+内心声音外化+世界观通过对话构建 |
| 借鉴点1 | **内心外化**：主角的不同"内心声音"代表不同认知维度——可映射为我们的社会化程度不同时解读同一对话的不同方式 |
| 借鉴点2 | **对话即玩法**：对话不是过场，是核心gameplay；每句话都可能是线索 |
| 规避陷阱 | 文本量极大（百万字），独立开发难以复制；我们要精炼而非堆量 |

### Steam 竞品现状

| 游戏 | 简述 | 核心缺陷 |
|------|------|---------|
| **Office Life（职场浮生记）** | 国产职场模拟RPG，厦门雷云出品，Steam已上线 | 经营/数值驱动，缺乏情感深度和识人机制 |
| **Office Simulator** | 纯办公室模拟，处理日常任务+员工管理 | 无叙事，无社交推理，是"工作模拟"不是"职场人生模拟" |
| **中国式家长/人生重开** | 人生模拟养成 | 职场只是人生一部分，大厂文化完全缺席 |

**差异化空间：**
1. **中国大厂文化视角**：目前没有任何游戏聚焦这个具体场景，空白市场
2. **识人作为核心玩法**：现有竞品没有"社交推理"维度，全是属性数值驱动
3. **情感密度**：现有中文职场游戏普遍缺乏真实的情感共鸣，停留在"职场攻略"层面

## 三、影视参考补充

### 《未生（미생）》— 韩剧
| 项目 | 内容 |
|------|------|
| 核心主题 | 非精英路线进入职场，用围棋思维理解组织权力结构 |
| 借鉴点 | **职场即棋局**：每个人的位置都有战略意义，NPC设计可借鉴"棋子视角"——每个人都在走自己的棋 |
| 情感借鉴 | 失败者的尊严感——"我虽然没赢，但我认真下过"，对应我们"没有失败只有选择"的设计 |

### 《半泽直树》— 日剧
| 项目 | 内容 |
|------|------|
| 核心主题 | 职场复仇+组织权力对抗，"以牙还牙，加倍奉还" |
| 借鉴点 | **权力结构可视化**：剧里通过台词和行为把组织权力关系写得极清晰，是"读局"维度的绝佳参考 |
| 规避陷阱 | 爽感太强，道德太明确（坏人就是坏人）；我们要的是模糊地带 |

### 《年会不能停！》— 国产电影
| 项目 | 内容 |
|------|------|
| 核心主题 | 大厂裁员+底层员工视角，荒诞喜剧外壳包裹真实焦虑 |
| 借鉴点 | **荒诞感**：大厂的某些规则本身就是荒诞的，游戏可以用轻喜剧方式呈现；让玩家"又笑又心疼" |

## 四、精神内核整合

### 参考矩阵

| 作品 | 给游戏的 | 关键词 |
|------|---------|--------|
| **《天道》** | 思想骨架 | 规律、识道、无救世主、强弱文化 |
| **《凡人歌》** | 情感血肉 | 共情、真实困境、镜子、身份危机 |
| **《未生》** | 职场结构感 | 棋局、组织权力、失败者的尊严 |
| **《半泽直树》** | 权力可视化 | 组织政治、读局能力 |
| **《年会不能停》** | 荒诞底色 | 大厂规则的荒诞性、轻喜剧张力 |
| **Papers Please** | 识人机制 | 信息不对称、代价感 |
| **Disco Elysium** | 对话深度 | 内心外化、认知维度差异 |
| **Florence** | 情感节奏 | 玩法即情绪、节奏控制 |
| **游戏灵魂句** | 情感温度 | 清醒后仍然热烈、逃亡也是勇气 |

### 综合精神内核

> 用天道的冷静看职场，用凡人歌的温度感受职场，用未生的棋局理解权力，用灵魂句的勇气选择离开——或留下。

### 社会化程度二维框架

```
         高清醒
            ↑
    "识道者" │ "清醒入局者"
（沈磊？）   │（芮小丹/张皓宇型）
            │
低融入 ──── ┼ ──── 高融入
            │
  "天真者"  │ "被同化者"
（刚入职）  │（那伟型玩家）
            ↓
         低清醒
```

360评估测的是这两个维度的组合，不是单一分数。
