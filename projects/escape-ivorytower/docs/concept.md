## 一句话描述

一个关于"你是怎么变成现在这个样子"的游戏。
玩家在职场的每一次选择，都是在回答一个问题：**你愿意为了留下来，付出多少自己？**

---

## 职场生命周期（主线流程）

```
校招 → 提前实习 → 正式入职 → 培训 → 转正 → 绩效考核
  → 晋升 → 升职加薪 → 跳槽 → ……
```

这不是线性路径，玩家可以在任意节点做出不同选择，走向不同的人生轨迹。

---

## 核心玩法

### 识人与社交推理
玩家通过三种方式"读懂"职场中的人：
1. **对话解读**：同一句话背后可能有多层意思，玩家需要判断真实意图
2. **信息线索收集**：通过观察、打听、文件等方式拼凑出他人的真实诉求
3. **行为模式观察**：一个人做了什么比说了什么更重要

### 360评估（核心量化机制）
- 游戏阶段性触发"360评估"
- 评估玩家当前的**社会化程度**（0-100分）
- 社会化程度是游戏最核心的量化指标
- 不代表好坏，代表你对"这个世界真实规则"的认知深度
- 评估结果影响后续选项的解锁和NPC对玩家的态度

### 选择与代价
- **没有失败**，每条路都能走下去
- 但每个选择都有真实的得失——留下来有代价，离开有代价，向上爬有代价，躺平有代价
- 开放式结局，玩家自由探索

## 情感目标

### 目标受众（三类，本质是同一个人的三个阶段）

| 类型 | 描述 | 游戏给他们的 |
|------|------|------------|
| **天真者** | 未经世事的学生和应届生，对职场有美好向往，社会化程度低 | 预演和认知——"原来真实的职场是这样的" |
| **成长者** | 初入职场到站稳脚跟，逐渐被改造，但也在努力改造环境 | 共鸣和镜子——"我正在经历这个" |
| **老炮们** | 已被岁月打磨，或收起豪情或继续追梦，故事丰富 | 被看见——"有人记录了这一切" |

### 玩完之后的感受
- "太真实了"
- "我在现实里也遇到过这个"
- 某种说不清楚的复杂情绪——不是爽，不是悲，是**被理解了**

## 差异化

| 对比游戏 | 借鉴点 | 我们的不同 |
|---------|--------|----------|
| 中国式家长 | 人生阶段模拟、养成成长 | 我们聚焦职场，深度在"识人"而非属性养成 |
| Papers Please | 信息判断、道德压力、每次选择的代价 | 我们没有"正确答案"，社会化不等于道德高下 |
| Florence | 情感叙事、生活切片、共鸣感 | 我们有更多主动决策，不是纯叙事 |
| Disco Elysium | 对话深度、角色内心、世界观构建 | 规模更小，但情感密度类似 |

## 已确认的约束

- 单机，无需服务器
- Godot 4 + GDScript
- 第一版先做核心循环（校招→实习→入职→第一次360评估）
- **美术风格：扁平插画风（clean flat illustration），参考 Florence 风格**
  - NPC 差异化通过面部表情 + 人物装扮实现，凸显人物特征或营造反差感
  - 已验证 image_gen 可稳定产出此风格
  - 美术生产路径：
    - NPC 对话立绘（静态）→ 直接 image_gen
    - NPC 行走/动作动画 → 2D精灵生成 skill（切帧+去背）
    - 场景背景 → 2D地图生成 skill
    - UI 元素 → image_gen 或 UX设计师 skill
- 数值框架：Summer哥有战斗类游戏数值经验（TTK框架），职场模拟的数值逻辑另行讨论

## 待解决问题（OPEN_QUESTIONS）

| 问题 | 优先级 | 备注 |
|------|--------|------|
| 社会化程度的具体评分维度是什么 | 高 | 草稿框架：读人（识别真实意图）/ 读局（理解权力结构）/ 读自己（自我认知）三维度；腾讯360是多方互评计分制，待Summer哥结合实际经验完善 |
| NPC 设计原则——类型化还是真实化 | 高 | **已确定：真实化**。每个NPC有三层：表层（展示给你的样子）/ 中层（真实诉求）/ 底层（人生处境和价值观）。玩家通过对话/线索/观察逐层剥开。社会化程度越高能看穿的层数越多。NPC行为有内在一致性，不随机善变。 |
| 游戏时长定位（一局多长） | 中 | **已确定：单周目约20h**。Demo只做前1-2h验证核心循环。 |
| 是否有多周目机制 | 中 | **待定**：有多周目意向，形式未定（下一代？从大学选专业重来？其他？），后续确认。 |
| 跳槽机制的边界（能跳几次？跳去哪？） | 中 | **已确定**：理论上无限跳，但有忠诚度（玩家侧）和稳定性（被评估侧）两个数值作为跳槽代价。游戏内有多家公司设定：大厂/中厂/小厂均有。 |
| 大厂背景是否明示（暗示腾讯？泛化？） | 低 | **已确定**：不明示但有隐晦暗示。示例：大鹅公司（腾讯/企鹅）、线难（网易）、代码滚动（字节？）等谐音/隐喻命名，懂的人秒懂，规避法律风险。 |
